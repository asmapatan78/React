DOM (Document Object Model) events in web development are actions that happen in the browser, which JavaScript can respond to. These events include user interactions (like clicks and key presses), as well as changes in the state of the page (like loading, resizing, or submitting a form).

Common DOM Events
Here are some common DOM events:

Mouse Events:

click: Fired when an element is clicked.
dblclick: Fired when an element is double-clicked.
mouseover: Fired when the mouse pointer moves over an element.
mouseout: Fired when the mouse pointer moves out of an element.
mousemove: Fired when the mouse pointer moves within an element.
mousedown: Fired when a mouse button is pressed down on an element.
mouseup: Fired when a mouse button is released over an element.
Keyboard Events:

keydown: Fired when a key is pressed down.
keyup: Fired when a key is released.
keypress: Fired when a key is pressed down and held (deprecated).
Form Events:

submit: Fired when a form is submitted.
change: Fired when the value of an input element changes.
input: Fired when the value of an input or textarea is changed.
focus: Fired when an element gains focus.
blur: Fired when an element loses focus.
Window Events:

load: Fired when the whole page has loaded, including all dependent resources (images, scripts, etc.).
resize: Fired when the browser window is resized.
scroll: Fired when the document view or an element is scrolled.
Document Events:

DOMContentLoaded: Fired when the HTML document has been completely loaded and parsed, without waiting for stylesheets, images, and subframes to finish loading.

Event Propagation
Event Bubbling: Events triggered on an element first trigger on that element, then bubble up to the parent elements.
Event Capturing: The opposite of bubbling, where the event is first captured by the outermost element and then propagated to the target.
You can control the event flow using methods like event.stopPropagation() and event.preventDefault().


<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Event Propagation Example</title>
</head>
<body>
    <div id="outerDiv" style="padding: 20px; background-color: lightblue;">
        Outer Div
        <div id="innerDiv" style="padding: 20px; background-color: lightgreen;">
            Inner Div
        </div>
    </div>

    <script>
        const outerDiv = document.getElementById('outerDiv');
        const innerDiv = document.getElementById('innerDiv');

        outerDiv.addEventListener('click', function() {
            alert('Outer Div Clicked!');
        });

        innerDiv.addEventListener('click', function(event) {
            alert('Inner Div Clicked!');
            // Stop the event from propagating to the outer div
            event.stopPropagation();
        });
    </script>
</body>
</html>

3. Hide and Show Elements
This example hides or shows a paragraph when a button is clicked.
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Hide and Show Elements</title>
</head>
<body>
    <p id="text">This text can be hidden or shown.</p>
    <button id="toggleTextBtn">Hide/Show Text</button>

    <script>
        const button = document.getElementById('toggleTextBtn');
        const text = document.getElementById('text');

        button.addEventListener('click', function() {
            if (text.style.display === 'none') {
                text.style.display = 'block';
            } else {
                text.style.display = 'none';
            }
        });
    </script>
</body>
</html>

let display = document.getElementById('display');
let currentInput = '';
let currentOperation = null;
let firstOperand = null;

function appendNumber(number) {
    currentInput += number;
    display.value = currentInput;
}

function chooseOperation(operation) {
    if (currentInput === '') return;

    if (firstOperand === null) {
        firstOperand = parseFloat(currentInput);
    } else if (currentOperation) {
        firstOperand = computeResult();
    }

    currentOperation = operation;
    currentInput = '';
}

function compute() {
    if (currentInput === '' || currentOperation === null) return;

    const secondOperand = parseFloat(currentInput);
    const result = computeResult(secondOperand);
    display.value = result;
    firstOperand = result;
    currentInput = '';
    currentOperation = null;
}

function computeResult(secondOperand = parseFloat(currentInput)) {
    let result;
    switch (currentOperation) {
        case '+':
            result = firstOperand + secondOperand;
            break;
        case '-':
            result = firstOperand - secondOperand;
            break;
        case '*':
            result = firstOperand * secondOperand;
            break;
        case '/':
            result = firstOperand / secondOperand;
            break;
        default:
            return;
    }
    return result;
}

function clearDisplay() {
    currentInput = '';
    currentOperation = null;
    firstOperand = null;
    display.value = '';
}
