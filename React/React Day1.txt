How to start with React?
	-> Install Node from nodejs.org (from the site select the latest stable version (LTS) 20 or 18)
	-> node --version, npm --version,(Node Package Manager) & npx --version (Node Package Execute)
	-> Need one editor application - vs code

	-> In Desktop create a new folder as 'React Projects'
	-> Open that folder in vscode.

	-> npx create-react-app projectname (node package exicutive)

	-> 2 possible errors,
	-> 'ENOENT' -> npm install create-react-app -g
	-> 'Network' -> check for the internet and re-run npx

	-> We need to check the project, we need to run and check the output.
	-> npm start (node package manager)


-> If you want to create a new page or style, we need to create a new file in html. but in react, we need to create a new components.


Components:
	-> components are the new js file, which will return the html command to App.js

Types:
	-> 1.stateless functinal components  2.stateful class components
	-> 1.stateless functinal components
		-> we will have function syntax in the new js file(components)

		-> create a new file as Greet.js inside components folder.
		-> we need to import the react
			import React from 'react';
		-> we need to create the function, use the keyword function
			-> one tag return
			function functionName(){
				return tag;
			}
			or
			-> multiple tag return
			function functionName(){
				return(
				<div>
					all the tags
				</div>
				);
			}

 export default Mass;


		-> we need to map the new js file with App.js, we are going to use import & export method
			-> export your new js file, with exportName -> same as functionName 
				export default exportName;

			-> import the exported file in App.js
				import exportName from './components/Greet'

		-> Last step is to create a new tag inside App.js div section with the same name as exportName.
			<div className='App'>
				<exportName/>
			</div>

Functional Component Props:
	-> props - properties
	-> in functional components, if you need to pass a value, we need create a new attribute in the function tag with a value.
		<Greet name="Vamsi Mitra"/>
		<Greet name="Pawan Kalyan"/>

	-> we need to change the Greet.js component
	in the function arguments, use props keyword
		function functionName(props){
			return {props.attributeName}
		}

		Eg.
		function Greet(props){
			return(
			<div>
				<h1>Welcome {props.name}</h1>
			</div>
			);
		}

one.js
import React from 'react';

// Define the Greet component
function Greet(props) {
  return (
    <div>
      <h2>Welcome {props.name}</h2>
    </div>
  );
}

// Main component
function Mass() {
  return (
    <div className="App">
      <header className="App-header">
        <h1>React Classes</h1>
        {/* Use the Greet component and pass the name prop */}
        <Greet name="Vamsi Mitra" />
        {/* Example of an inline function - corrected */}
        {functionName({ attributeName: 'example' })}
        <a href="#learn">
          Learn React from Vamsi sir's class
        </a>
      </header>
    </div>
  );
}

// Correct definition of functionName
function functionName(props) {
  return <div>{props.attributeName}</div>;
}

export default Mass;
