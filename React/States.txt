State
State is a built-in React object used to manage and track data that changes over time within a component.
Unlike props, state is mutable and can be updated using the setState method (or state updater function in functional components using the useState hook).
When state changes, the component re-renders to reflect the updated data.



->state is nothing but a variable declared within the body


props VS state:
props:
	->props get passed to the component
	->function parameters
	->props are immutable
	
	->props are accessed by using
	->props keyword in - functional components
	->this.props in - class components
	
	
state:
	->state is managed within the component
	->variables declared in the function body
	->state can be changed
	
->states are accessed by using
	->useState Hook in - functional components
	->this.state in class components

How the state should be changed:

->By using functional component:

greet.js:

import React, { useState } from 'react';

function Message() {
    const [message, setMessage] = useState('Pawan Kalyan');

    const changeMessage = () => {
        setMessage('Deputy Chief Minister');
    }

    return (
        <div>
            <h1>Happy Birthday {message}</h1>
            <button onClick={changeMessage}>Click Me</button>
        </div>
    );
}

export default Message;

import React ,{Component} from 'react'
class Counter extends Component{
    constructor(props){
        super(props)
        this.state = {
            count: 0
        }
    }

    increment(){
        this.setState({
            count: this.state.count + 1
        })
    }
    render(){
        return(
            <div>
                <h1>Count - {this.state.count}</h1>
                <button onClick={()=> this.increment()}>Increment</button>
            </div>
        )
    }

}
export default Counter;

Destructing state by using functional components:

greet.js:

import React, { useState } from 'react';

function Person() {
    // Using useState hook to manage state
    const [person, setPerson] = useState({
        firstName: 'Pawan',
        lastName: 'Kalyan',
        heroName: 'Power Star'
    });

    // Destructuring state
    const { firstName, lastName, heroName } = person;

    const changeName = () => {
        setPerson({
            firstName: 'Deputy',
            lastName: 'Cheif Minister',
            heroName: 'Andhra Pradesh'
        });
    }

    return (
        <div>
            <h1>Happy Birthday {heroName} {firstName} {lastName}</h1>
            <button onClick={changeName}>Change Name</button>
        </div>
    );
}

export default Person;

App.js:

import './App.css';
import React from 'react';
import Person from './component/Greet';

function App() {
  return (
    <>
      <Person></Person>
    </>
  );
}

export default App;

import React, { Component } from 'react';

class PersonClass extends Component {
    constructor() {
        super();
        // Initializing state
        this.state = {
            firstName: 'Pawan',
            lastName: 'Kalyan',
            heroName: 'Power Star'
        };
    }

    changeName = () => {
        this.setState({
            firstName: 'Ram',
            lastName: 'Charan',
            heroName: 'Mega Power Star'
        });
    }

    render() {
        // Destructuring state
        const { firstName, lastName, heroName } = this.state;

        return (
            <div>
                <h1>Hello {firstName} {lastName} also known as {heroName}</h1>
                <button onClick={this.changeName}>Change Name</button>
            </div>
        );
    }
}

export default PersonClass
